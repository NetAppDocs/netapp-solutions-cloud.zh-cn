= 防火墙
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Google Cloud NetApp Volumes公开多个 TCP 端口来为 NFS 和 SMB 共享提供服务：

* https://docs.cloud.google.com/netapp/volumes/docs/connect-clients/connect-nfs-clients#firewall_rules_for_nfs_volumes_access["NFS 访问所需的端口"^]
* https://docs.cloud.google.com/netapp/volumes/docs/connect-clients/connect-smb-clients#firewall_rules_for_smb_volumes_access["SMB 访问所需的端口"^]


此外，SMB、具有 LDAP（包括 Kerberos）的 NFS 和双协议配置都需要访问 Windows Active Directory 域。Active Directory 连接必须 https://docs.cloud.google.com/netapp/volumes/docs/configure-and-use/active-directory/create-ad-policy["配置"^]基于每个区域。Active Directory 域控制器（DC）是通过使用 https://docs.microsoft.com/en-us/openspecs/windows_protocols/ms-adts/7fcdce70-5205-44d6-9c3a-260e616a2f04["基于 DNS 的 DC 发现"^]并使用指定的 DNS 服务器来标识的。将使用返回的任何 DC。可以通过指定 Active Directory 站点来限制符合条件的 DC 列表。

Google Cloud NetApp Volumes 使用通过 `gcloud compute address`命令分配的 CIDR 范围中的 IP 地址进行访问，同时 https://docs.cloud.google.com/netapp/volumes/docs/plan-and-prepare/networking#configure_private_services_access["加入Google Cloud NetApp Volumes"^]。您可以将此 CIDR 用作源地址，以配置 Active Directory 域控制器的入站防火墙。

Active Directory 域控制器必须 https://docs.cloud.google.com/netapp/volumes/docs/plan-and-prepare/security-considerations["如此处所述，将端口暴露给Google Cloud NetApp Volumes CIDR"^]。
